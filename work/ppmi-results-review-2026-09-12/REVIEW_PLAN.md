# Post-analysis review specification

This public methods note accompanies the source and its provenance checks.
The review is exploratory and preserves the primary cohort and original gene
tests. Participant-specific review lists remain in private configuration.

Inspect Cook's distances and conditional omission sensitivity for flagged
observations. Review released site, demographic, collection and clinical fields
using their source dictionaries. Derive immune-expression marker summaries from
the documented MCP-counter definitions; treat these as expression proxies rather
than measured cell fractions. Fit covariate-adjusted score comparisons and
pathway-marker correlations using the source's correction rules.

Fit the site/race sensitivity only when the complete-case design is identifiable.
Retain source-row provenance, original tests and the separation between gene
influence diagnostics, descriptive biological review and discovery inference.
